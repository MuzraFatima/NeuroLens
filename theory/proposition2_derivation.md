## 1. Problem Setup: Multi-Parent Feature Hierarchy in Linear Representations

Let $x \in \mathbb{R}^d$ be a residual-stream activation generated by a ground-truth directed acyclic concept graph $\mathcal{G}^* = (V^*, E^*)$ over $|V^*| = M$ concepts. Following the hierarchical orthogonality principle of Park et al. (ICLR 2025), each concept $i \in V^*$ possesses a unit-norm **residual direction** $u_i \in \mathbb{R}^d$ ($\|u_i\|_2 = 1$) such that child residual directions are orthogonal to their ancestor residual directions:
$$\langle u_c, u_p \rangle = 0 \quad \forall (p \to c) \in E^*.$$

When a concept $c$ is active on token $t$ ($s_c(t) > 0$), all of its parents $p \in \mathrm{Pa}^*(c)$ are necessarily active ($s_p(t) > 0$ whenever $s_c(t) > 0$). Thus the ground-truth activation on token $t$ is:
$$x(t) = \sum_{i \in V^*} s_i(t)\, u_i + \epsilon(t),$$
where $\epsilon(t)$ is isotropic background noise. Crucially, unlike tree hierarchies where $|\mathrm{Pa}^*(c)| \le 1$, in a **mixed-topology DAG**, a fraction $\rho \in [0, 1]$ of child concepts have $|\mathrm{Pa}^*(c)| \ge 2$ parents (e.g., `"bat"` $\to \{\text{mammal}, \text{flier}\}$; `"Paris"` $\to \{\text{capital}, \text{French city}\}$).

## 2. Lemma 1: Frequency-Ordered Acyclicity & Partial Coverage Bound

### Statement (Lemma 1)
Let $f_i = \Pr(z_i > 0)$ denote the firing frequency of feature $i$.
1. **Exact Coverage:** If parent $p$ fires on every token where child $c$ fires ($\Pr(p \text{ active} \mid c \text{ active}) = 1$) and fires on at least one token where $c$ is inactive ($\Pr(p \text{ active} \mid c \text{ inactive}) > 0$), then:
   $$f_p > f_c.$$
   Consequently, restricting candidate directed edges $(p \to c)$ to pairs satisfying $f_p > f_c$ (with ties broken deterministically by latent index) guarantees that the resulting graph $G = (V, E)$ is a **strictly upper-triangular Directed Acyclic Graph (DAG)** ($A^H = 0$ for $H \ge |V|$) and retains $100\%$ of exact-coverage hierarchy edges without requiring continuous acyclicity penalties (such as $\mathrm{tr}(e^{A \circ A}) - d$) or combinatorial greedy cycle-removal loops.
2. **Partial Coverage ($\tau$-Relaxation):** Suppose parent $p$ covers child $c$ with conditional recall $\tau = \Pr(p \text{ active} \mid c \text{ active}) \in (0, 1]$ and fires outside $c$ at rate $\beta = \Pr(p \text{ active} \mid c \text{ inactive})$. Then:
   $$f_p = \tau f_c + (1 - f_c)\beta.$$
   Therefore, $f_p > f_c$ holds if and only if:
   $$\beta > \frac{(1 - \tau) f_c}{1 - f_c}.$$
   In particular, a true edge $(p \to c)$ violates frequency order only when $\beta \le \frac{(1-\tau)f_c}{1-f_c}$—that is, when $p$ almost never fires without $c$, which is precisely the near-duplicate/redundant regime rejected by AG-SAE's non-redundancy (NR) criterion.
3. **Invariance Under Ancestral Routing:** Under non-negative ancestral routing $z_{\text{eff}} = (I - A)^{-1} z$ with $A \ge 0$, for any edge $(p \to c)$ with $A_{p,c} > 0$, $z_{\text{eff}, p} \ge A_{p,c} z_{\text{eff}, c}$, so $z_{\text{eff}, c} > 0 \implies z_{\text{eff}, p} > 0$. Thus effective firing frequencies satisfy $f_p^{\text{eff}} \ge f_c^{\text{eff}}$, preserving topological validity.

### Proof
By the law of total probability:
$$f_p = \Pr(p \mid c)\Pr(c) + \Pr(p \mid \neg c)\Pr(\neg c) = \tau f_c + \beta(1 - f_c).$$
When $\tau = 1$ and $\beta > 0$ with $f_c < 1$, we immediately obtain $f_p = f_c + \beta(1 - f_c) > f_c$. Since $>$ defines a strict partial order on $\mathbb{R}$, any graph whose edges $(p \to c)$ strictly decrease the rank function $r(i) = f_i$ cannot contain a directed cycle $v_1 \to v_2 \to \dots \to v_k \to v_1$, because $f_{v_1} > f_{v_2} > \dots > f_{v_1}$ is impossible. For $\tau < 1$, rearranging $\tau f_c + \beta(1 - f_c) > f_c$ yields $\beta(1 - f_c) > (1 - \tau)f_c$, completing the proof. $\blacksquare$

## 3. Proposition 1: Sparsity-Neutral Ancestry Removes the Absorption Incentive

### Statement (Proposition 1)
Consider a child concept $c$ with parent set $\mathrm{Pa}^*(c) = \{p_1, \dots, p_m\}$, where on child-active tokens ($s_c > 0$), each parent has conditional expectation $\mu_i = \mathbb{E}[s_{p_i} \mid s_c > 0]$ and zero conditional variance ($\sigma_i^2 = 0$), with $s_c = 1$ on child tokens.
- In a **flat $L_0$-penalized (or TopK) SAE** with penalty $\lambda > 0$ per active native code:
  - The **Non-Absorbed Dictionary** ($d_c = u_c, d_{p_i} = u_{p_i}$) requires firing $1 + m$ latents on every child token, incurring native sparsity cost $(1 + m)\lambda$ per child token.
  - The **Fully Absorbed Dictionary** ($d_c^{\text{abs}} = u_c + \sum_{i=1}^m \mu_i u_{p_i}, d_{p_i} = u_{p_i}$) suppresses all $m$ parent latents on child tokens ($z_{p_i} = 0$) and fires only $z_c = 1$, achieving zero reconstruction error on child tokens at native sparsity cost $\lambda < (1 + m)\lambda$. Hence flat sparsity strictly prefers absorbing all $m$ parents.
- In **DR-SAE** with ancestral readout $z_{\text{eff}} = (I - A)^{-1} z$ and $\hat{x} = R z_{\text{eff}}$:
  - Setting $R_c = u_c$, $R_{p_i} = u_{p_i}$, and $A_{p_i, c} = \mu_i$ allows the encoder to fire **only** $z_c = 1$ (native $L_0 = 1$, native sparsity cost $\lambda$) while producing $z_{\text{eff}, c} = 1$ and $z_{\text{eff}, p_i} = \mu_i > 0$, yielding:
    $$\hat{x} = R_c z_{\text{eff}, c} + \sum_{i=1}^m R_{p_i} z_{\text{eff}, p_i} = u_c + \sum_{i=1}^m \mu_i u_{p_i} = x.$$
  - Both the absorbed and non-absorbed solutions incur identical native $L_0 = 1$, while the orthogonality penalty $\lambda_\perp \sum_{(p,c) \in E} \langle r_p, r_c \rangle^2$ is strictly zero for the residual dictionary ($R_c = u_c \perp u_{p_i}$) and strictly positive ($\lambda_\perp \sum_{i=1}^m \mu_i^2 / \|d_c^{\text{abs}}\|_2^2 > 0$) if $R_c$ absorbs any parent direction. Thus the unique global minimizer of the DR-SAE objective has **zero parent false negatives (zero absorption)** and **pure orthogonal residual atoms**. $\blacksquare$

## 4. Proposition 2: Selective Multi-Parent Absorption Phase Boundary

### Statement (Proposition 2 — Selective Absorption Law)
Let a child concept $c$ occur with probability $f_c = \Pr(c \text{ active}) > 0$ and have $m \ge 2$ true parents $\mathrm{Pa}^*(c) = \{p_1, \dots, p_m\}$ with pairwise orthogonal unit directions $\{u_c, u_{p_1}, \dots, u_{p_m}\}$. Conditional on $c$ being active (with normalized child coefficient $s_c = 1$), suppose each parent's ground-truth activation coefficient $s_{p_i}$ has conditional mean $\mu_i = \mathbb{E}[s_{p_i} \mid c]$ and conditional variance:
$$\sigma_i^2 = \mathrm{Var}(s_{p_i} \mid c \text{ active}), \quad i \in \{1, \dots, m\}.$$
Consider a flat sparse autoencoder with per-token $L_0$ penalty weight $\lambda > 0$ (or Lagrange multiplier $\lambda(k)$ induced by a TopK constraint). On child-active tokens, the SAE must choose for each parent $p_i$ whether to:
1. **Keep $p_i$ Separate (Unabsorbed):** Fire native latent $z_{p_i} = s_{p_i}$ alongside $z_c = 1$, paying sparsity cost $\lambda$ and zero conditional reconstruction error along $u_{p_i}$.
2. **Absorb $p_i$ into $c$'s Atom:** Set $z_{p_i} = 0$ on child tokens and fold the best constant multiple $\alpha_i u_{p_i}$ into the child's decoder vector $d_c$.

Then:
1. **Optimal Absorbed Coefficient & Residual Error:** If parent $p_i$ is absorbed into $d_c$ while $z_c = 1$ on child tokens, the MSE-optimal absorbed component is $\alpha_i^* = \mu_i$, which leaves an irreducible expected squared reconstruction error per child token of:
   $$\mathcal{E}_{\text{abs}}(p_i) = \mathbb{E}\big[(s_{p_i} - \alpha_i^*)^2 \mid c \text{ active}\big] = \sigma_i^2.$$
2. **Per-Parent Phase Boundary:** Absorbing parent $p_i$ strictly reduces the expected total per-child-token objective $\mathcal{J}_i = \mathbb{E}[\|x - \hat{x}\|_2^2 + \lambda \|z\|_0 \mid c]$ if and only if:
   $$\sigma_i^2 < \lambda.$$
3. **Selective Absorption Ordering:** Suppose the parents are ordered by conditional magnitude variance:
   $$\sigma_{(1)}^2 < \sigma_{(2)}^2 < \dots < \sigma_{(m)}^2.$$
   As the sparsity pressure $\lambda$ increases (or as budget $k$ decreases), parents are absorbed into $c$ in **strictly increasing order of their conditional variance $\sigma_i^2$**. Specifically, when $\sigma_{(1)}^2 < \lambda < \sigma_{(2)}^2$, **selective partial absorption** occurs: parent $p_{(1)}$ (the more rigid/consistent parent) is absorbed into $c$, whereas parent $p_{(2)}$ (the more variable parent) remains unabsorbed.

### Complete Derivation
Because $\{u_c, u_{p_1}, \dots, u_{p_m}\}$ are orthonormal, on any child-active token ($c$ active, $s_c = 1$), the ground-truth vector projected onto the subspace $\mathcal{S}_c = \mathrm{span}(u_c, u_{p_1}, \dots, u_{p_m})$ is:
$$x_{\mathcal{S}_c} = u_c + \sum_{i=1}^m s_{p_i} u_{p_i}.$$
Let $A_{\text{abs}} \subseteq \{1, \dots, m\}$ denote the subset of parents absorbed into $c$ (so $z_{p_i} = 0$ on child tokens for $i \in A_{\text{abs}}$), and let $U = \{1, \dots, m\} \setminus A_{\text{abs}}$ be the unabsorbed parents (so $z_{p_j} = s_{p_j} > 0$ on child tokens for $j \in U$).

Write the child's unnormalized effective decoder vector in $\mathcal{S}_c$ as:
$$\tilde{d}_c = u_c + \sum_{i \in A_{\text{abs}}} \alpha_i u_{p_i}.$$
For $z_c = 1$ and $z_{p_j} = s_{p_j}$ ($j \in U$), the reconstruction on a child token is:
$$\hat{x}_{\mathcal{S}_c} = u_c + \sum_{i \in A_{\text{abs}}} \alpha_i u_{p_i} + \sum_{j \in U} s_{p_j} u_{p_j}.$$
By Parseval's identity across the orthonormal basis $\{u_c, u_{p_1}, \dots, u_{p_m}\}$, the expected reconstruction error conditioned on $c$ being active decouples additively across parents:
$$\mathbb{E}\big[\|x_{\mathcal{S}_c} - \hat{x}_{\mathcal{S}_c}\|_2^2 \;\big|\; c\big] = \sum_{i \in A_{\text{abs}}} \mathbb{E}\big[(s_{p_i} - \alpha_i)^2 \;\big|\; c\big] = \sum_{i \in A_{\text{abs}}} \Big(\mathrm{Var}(s_{p_i} \mid c) + (\mu_i - \alpha_i)^2\Big).$$
Minimizing over $\alpha_i$ yields $\alpha_i^* = \mu_i$, reducing the reconstruction penalty to $\sum_{i \in A_{\text{abs}}} \sigma_i^2$. Meanwhile, the expected $L_0$ penalty on a child token is:
$$\lambda \big(1 + |U|\big) = \lambda(1 + m) - \sum_{i \in A_{\text{abs}}} \lambda.$$
Combining reconstruction error and sparsity cost, the total conditional objective on child tokens is:
$$\mathcal{J}(A_{\text{abs}}) = \lambda(1 + m) + \sum_{i \in A_{\text{abs}}} \big(\sigma_i^2 - \lambda\big).$$
Since each term $(\sigma_i^2 - \lambda)$ is independent, $\mathcal{J}(A_{\text{abs}})$ is minimized by choosing:
$$A_{\text{abs}}^*(\lambda) = \big\{ i \in \{1, \dots, m\} : \sigma_i^2 < \lambda \big\}.$$
When $m = 1$, this recovers the single-parent HiPACE phase boundary (Zhang et al., 2026). When $m \ge 2$, it establishes the **Selective Multi-Parent Absorption Law**:
- **Regime I ($\lambda < \min(\sigma_1^2, \sigma_2^2)$):** Neither parent is absorbed ($A_{\text{abs}}^* = \emptyset$).
- **Regime II ($\sigma_1^2 < \lambda < \sigma_2^2$):** Parent $p_1$ is selectively absorbed while $p_2$ continues to fire ($A_{\text{abs}}^* = \{1\}$).
- **Regime III ($\sigma_2^2 < \lambda < \sigma_1^2$):** Parent $p_2$ is selectively absorbed while $p_1$ continues to fire ($A_{\text{abs}}^* = \{2\}$).
- **Regime IV ($\lambda > \max(\sigma_1^2, \sigma_2^2)$):** Joint absorption—both parents $p_1$ and $p_2$ are simultaneously absorbed into $c$ ($A_{\text{abs}}^* = \{1, 2\}$). $\blacksquare$
